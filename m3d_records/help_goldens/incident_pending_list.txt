                                                                                                    
 Usage: physicore-collector incident pending list [OPTIONS] {out_dirs}...                           
                                                                                                    
 List capture sessions that still need an incident package, whether each can proceed NOW, and what  
 to do if not.                                                                                      
                                                                                                    
 Covers sessions whose preparation was deferred or failed, finished sessions nobody prepared, and   
 stale `running`                                                                                    
 sessions left by a crash, power loss or reboot. Read-only: nothing is hashed, recovered, signalled 
 or written.                                                                                        
                                                                                                    
 Exit code: 0 = listed, 2 = a path is not a directory.                                              
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    out_dirs      <path>  Capture output directory (or several) holding the session             │
│                            directories.                                                          │
│                            [required]                                                            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --guard-dir        <path>  Also check this directory for an active capture (repeatable).         │
│ --json                     Machine-readable JSON output.                                         │
│ --help                     Show this message and exit.                                           │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
